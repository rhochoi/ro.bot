> ro는 **도구 모음**이다. 질문과 학습은 하지 않는다. 질문은 Claude Code에서 하고, UI·브라우저 작업만 `scripts/delegate.sh agy`로 위임한다.

## 1. 원칙

1. **답하지 않는다**: ro는 질문에 답하거나 엔진을 고르지 않는다. 질문은 Claude Code에서 하고, ro는 파일 찾기·정리·기록만 한다.
2. **ro가 한 일만 기록한다**: 정리·점검·기록·펫 이벤트는 로컬 로그(`~/.ro/log`)에 남기고, 쓰기는 되돌릴 수 있게 한다. 사용자의 활동(셸·git·세션)은 수집하지 않는다.
3. **읽기 우선, 쓰기는 승인**: 로컬 되돌릴 수 있는 수정만 자율. 외부 전송·삭제·구매·계정·보안은 직전 승인 (`~/.codex/AGENTS.md` 권한 규칙 상속).
4. **비밀 불저장**: 비밀번호·키·토큰은 기억·로그 어디에도 남기지 않는다.
5. **증거 > 기억**: 기억은 힌트, 현재 상태 확인이 우선.

## 2. 구조 (층 셋 = 3 레이어)

| 층 | 역할 | 구현 |
|---|---|---|
| 머리 (Head) | 승인 게이트 | 펫의 승인 카드, 안전 훅 |
| 몸 (Body) | 컴퓨터 이해: 프로젝트·도구·설정 지도 | `map/` 읽기 전용 스캔 → 구조화 인덱스 |
| 바닥 (Base) | 기록: 이벤트 로그, 결정, 선호 | `log/` append-only (JSONL) + 요약 |

## 3. 엔진 라우팅 — 폐기 (2026-10-27)

코드는 제거했다. 위임 대상은 UI·브라우저 작업의 `agy`뿐이다(`scripts/delegate.sh`).

## 4. 개인화 발전 단계 (각 단계 30분 단위로 분할)

0. **Seed**: 이 문서, 정책, 로그 스키마. — 유지
1. **Map**: `~/Claude`, `~/Downloads`, `~/.codex` 등 읽기 전용 스캔 → 프로젝트·도구 지도 생성 (비밀 파일 제외 목록 포함). — 유지
2. **Log**: ro가 한 작업을 JSONL로 기록, 일일 요약 생성. — 유지(ro 자신의 로그만)
3. **Route**: 엔진 어댑터 3종 + 수동 라우팅 → 로그 기반 추천 라우팅. — **폐기**
4. **Learn**: 반복 수정·선호를 후보로 제안 → 사용자 승인 후에만 규칙화. — **폐기**
5. **Harden**: 평가 체크리스트(회귀), 권한 감사, 실패 재현 테스트. — 유지(점검 9개 + 안전 훅)
6. **Ambient**: 장치(시리얼 `serial_link.py` 등)·알림·일정 입력 채널 확장. — **폐기**(`serial_link.py`는 독립 도구로 남음)

각 단계 종료 조건: 실행·검증 증거 + 롤백 방법.

## 5. 브랜드 → UI 매핑 (`ro pet`)

- 표정: 기본(`idle`) / 기록 중(`recording`) / 집중(`focus`) / 불안(`anxious`: 권한 필요·오류) / 발견(`discovery`) / 풀어냄(`resolved`: 완료) — `focus`·`discovery`는 미리보기 메뉴에서만 볼 수 있다(상태로는 나오지 않음)
- 상태 표시 = 층 애니메이션 (표정에 따라 층이 어긋나거나 들린다. 층의 크기는 기록량과 무관하다)
- 색은 둘(검정 `#141413`·크림 `#F5F2EB`), 메뉴바 아이콘은 16px 전용 버전
- 실행: `python -m ro pet` (macOS 데스크톱 투명 오버레이 + 16px 메뉴바 상주, 클릭 시 말풍선(기록·파일 찾기·정리)과 쓰기 승인 게이트)
